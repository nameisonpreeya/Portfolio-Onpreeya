# Portfolio-Onpreeya
Portfolio | Onpreeya Rompho
Personal portfolio website of Onpreeya Rompho, an IT student at Mahidol University (Digital Science and Technology), built to showcase academic projects, skills, and experience for internship applications.

Sections
Professional Summary: short introduction and internship objective
Education: university, program, and GPA
Skills: technology skills and soft skills
Academic Projects: project cards with a "Read More" popup showing role, details, and links to reports, mockups, and previews
Work Experience: part-time work history

Tech Stack
HTML and Tailwind CSS (via CDN, no build step)
Font Awesome for icons
Google Fonts: Inter and Noto Sans Thai
Vanilla JavaScript for the project popups (open, close, click outside, Esc key)
